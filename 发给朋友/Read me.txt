Sundial — Claude Code 桌宠
==========================

一只停在桌面上的小太阳，显示正在跑的 Claude Code 会话
（在想什么、想了多久、上下文用了多少），
以及——如果你有 Claude Max / Pro 订阅——用量还剩多少。

需要 macOS 13 或更新的版本，Intel 和 Apple 芯片都能跑。


先说清楚：不登录也能用
----------------------

这个 App 的两半是分开的：

  · 会话状态、上下文占用 —— 读你自己电脑上的本地文件，
    不需要账号、不需要订阅，装上就能看。

  · 两个用量圈 —— 需要 Claude Max 或 Pro 订阅。
    没有订阅的话，Claude 的授权页会直接拒绝连接，登不上去是正常的，
    不是这个 App 坏了。

所以：**没订阅就跳过登录那一步**，太阳和会话块照样正常工作，
只是没有那两个圈。

（授权页上写的「或使用 API 密钥」对这一半没用——那是另一套计费方式，
 没有"订阅用量"这个数可显示。）


第一次打开（重要）
------------------

这个 App 没有经过 Apple 公证，所以系统第一次会拦一下。二选一：

【方法一 · 最省事】
把 Sundial.app 拖到「应用程序」文件夹，然后打开「终端」，粘贴这行回车：

    xattr -dr com.apple.quarantine /Applications/Sundial.app

之后双击就能正常打开，只需做这一次。

【方法二】
双击打开，系统会拦住并提示「无法打开」。
去「系统设置 › 隐私与安全性」，往下滚，会看到一行关于 Sundial 的提示，
点「仍要打开」。


怎么登录（有 Max/Pro 才需要）
-----------------------------

1. 打开后，桌面右下角会出现一只灰扑扑、正在打盹的小太阳。
   没有会话在跑、也还没登录时，底下会有一张小卡片和「双击登录」按钮。
2. 双击太阳（或点那个按钮）→ 浏览器会打开 Claude 的授权页面。
3. 在浏览器里登录你自己的 Claude 账号，点授权。
4. 页面会给出一段授权码，复制它，粘贴回小太阳弹出的输入框，点「完成登录」。
5. 之后它会自己刷新，不用再管；登录也只做这一次。

   ⚠️ 如果授权页写着「连接 Claude Code 需要 Claude Max 或 Pro」，
      那就是这个账号没有订阅——登不上去，跳过即可，会话那半边照常用。

   ⚠️ 有订阅却登不上，最常见的原因是浏览器里还留着以前的授权页标签，
      从旧页面复制了码。把这类旧标签全部关掉，重新点一次登录，
      只用刚打开的那一页上的码。每个授权码只能用一次，放太久也会失效。


你会看到什么
------------

闲着的时候，桌面上只有一颗太阳，没有卡片也没有底——
这是正常的，没有事情发生的时候不占地方。鼠标移上去就会展开。

展开以后：太阳在中间，有订阅的话左右各一个圈。

  · 左边的圈（蜜金色）= 5 小时限额用了多少
  · 右边的圈（杏粉色）= 用得最紧的那条每周限额。
    标签可能写「每周」，也可能写某个模型的名字——哪条最紧就显示哪条。
  · 中间的太阳：心情跟着用量走。轻松时咧嘴笑，用了一半抿着嘴，
    快用满了会皱眉、身体发红。
    它还会往用得紧的那一侧探出光芒来回摆动，尖上亮起那一侧的颜色，
    越满越亮——所以收起来只剩一颗太阳时，扫一眼也知道哪边紧张。
  · 下面每有一个正在跑的 Claude Code 会话就是一块，写着标题、
    正在做什么、已经跑了多久、上下文用了多少。
    抛出选项等你选的那一条会排到最上面。
  · 鼠标停一会儿，最下面会展开明细。

太阳灰扑扑地睡觉、冒 zzz，意思是现在没有会话在跑，不是坏了。


怎么操作
--------

  拖动          = 移动位置（放哪儿它记得住）
  双击          = 没登录时开始登录；登录了就是立刻刷新一次
  点一下会话块  = 把这条「跑完了还没看」的提示消掉
  右键          = 菜单
  鼠标移上去    = 展开明细，移开自动收起

菜单栏右上角也有一颗小太阳，**有会话在跑时它会转**。
点它有菜单：立即刷新、登录 / 退出登录、显示用量明细、打开网页版用量、
更通透的玻璃、始终置于其他窗口之上、登录时自动启动、
把桌宠移回屏幕中央、退出。

桌宠被拖到看不见的地方时（拔掉外接显示器之后最容易碰到），
从菜单栏那个太阳里点「把桌宠移回屏幕中央」就能叫回来。


需要什么
--------

· 装了 Claude Code —— 会话那半边靠它，这是主要功能
· 一个 Claude Max / Pro 订阅 —— 只有那两个圈需要，没有也能用


常见问题
--------

Q：太阳一直灰着不动？
A：说明没有检测到正在跑的 Claude Code 会话，这是正常的空闲状态。

Q：会话块里那个百分比是什么？
A：上下文窗口用了多少。条子变深红就说明快满了，该考虑新开一个会话。

Q：一直显示「未登录」？
A：如果没有 Max/Pro，这就是正常的，不影响会话显示。
   有订阅的话双击太阳重新走一遍登录，注意别用旧标签页上的授权码。

Q：数字和 Claude Code 里 /usage 看到的一样吗？
A：一样，同一个来源。每分钟自己更新一次，想立刻更新就双击。

Q：它会一直占着 CPU 吗？
A：不会。没在跑会话时降到低帧率，显示器一睡就完全停下来。

Q：它会上传我的东西吗？
A：不会。会话那半边只读本地文件，而且只看类型、时间戳这几个字段，
   不读对话正文。登录令牌只存在你自己电脑上，不发往任何地方。
