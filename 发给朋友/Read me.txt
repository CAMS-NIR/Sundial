Sundial — Claude Code 用量桌宠
==============================

一只停在桌面上的小太阳，显示你的 Claude 用量还剩多少，
以及正在跑的 Claude Code 会话（在想什么、想了多久、上下文用了多少）。

需要 macOS 13 或更新的版本，Intel 和 Apple 芯片都能跑。


第一次打开（重要）
------------------

这个 App 没有经过 Apple 公证，所以系统第一次会拦一下。二选一：

【方法一 · 最省事】
把 Sundial.app 拖到「应用程序」文件夹，然后打开「终端」，粘贴这行回车：

    xattr -dr com.apple.quarantine /Applications/Sundial.app

之后双击就能正常打开，只需做这一次。

【方法二】
双击打开，系统会拦住并提示「无法打开」。
去「系统设置 › 隐私与安全性」，往下滚，会看到一行关于 Sundial 的提示，
点「仍要打开」。


怎么登录
--------

1. 打开后，桌面右下角会出现一只灰扑扑、正在打盹的小太阳，
   底下一张小卡片写着「未登录」，还有个橙色的「双击登录」按钮。
2. 双击太阳（或点那个按钮）→ 浏览器会打开 Claude 的授权页面。
3. 在浏览器里登录你自己的 Claude 账号，点授权。
4. 页面会给出一段授权码，复制它，粘贴回小太阳弹出的输入框，点「完成登录」。
5. 之后它会自己刷新，不用再管；登录也只做这一次。

   ⚠️ 登录失败最常见的原因：浏览器里还留着以前的「Authentication code」
      标签页，从旧页面复制了码。把这类旧标签全部关掉，重新点一次登录，
      只用刚打开的那一页上的码。每个授权码只能用一次，放太久也会失效。


你会看到什么
------------

闲着的时候，桌面上只有一颗太阳，没有卡片——
这是正常的——没有事情发生的时候不用占地方。鼠标移上去就会展开。

展开以后是这样：太阳在中间，左右各一个圈。

  · 左边的圈 = 5 小时限额用了多少
  · 右边的圈 = 用得最紧的那条每周限额（所以标签可能写「每周」，
    也可能写某个模型的名字——哪条最紧就显示哪条）
  · 中间的太阳 = 心情跟着用量走：轻松时咧嘴笑，用了一半抿着嘴，
    快用满了会皱眉、身体发红。
    它还会往用得紧的那一侧探出光芒来回摆动，尖上亮起那一侧的颜色，
    越满越亮。所以就算收起来只剩一颗太阳，扫一眼也知道哪边紧张。
  · 下面每有一个正在跑的 Claude Code 会话就是一块，写着标题、
    正在做什么、已经跑了多久、上下文用了多少。
  · 鼠标停一会儿，最下面会展开每条限额的明细和上次更新时间。

太阳灰扑扑地睡觉、冒 zzz，意思是现在没有会话在跑，不是坏了。
如果它睡着而且卡片上写了一行提示（比如「登录已失效」），那才是真有问题。


怎么操作
--------

  拖动          = 移动位置（放哪儿它记得住）
  双击          = 没登录时开始登录；登录了就是立刻刷新一次
  点一下会话块  = 把这条「跑完了还没看」的提示消掉
  右键          = 菜单
  鼠标移上去    = 展开明细，移开自动收起
  菜单栏的太阳  = 找不到窗口时，从这里点「把桌宠移回屏幕中央」

右键菜单里有：登录 / 退出登录、立即刷新、显示用量明细、
打开网页版用量、更通透的玻璃、始终置于其他窗口之上、
登录时自动启动、退出。
（「把桌宠移回屏幕中央」只在菜单栏那个太阳的菜单里。）


需要什么
--------

· 一个 Claude 订阅账号（两个圈靠它）
· 想看「正在跑的会话」那部分的话，需要装 Claude Code；不装也能看用量


常见问题
--------

Q：太阳不见了？
A：菜单栏最右边有一个小太阳图标，点它 →「把桌宠移回屏幕中央」。
   （拔掉外接显示器之后最容易碰到。）

Q：一直显示「未登录」？
A：双击太阳重新走一遍登录。如果反复失败，多半是复制了旧标签页上的授权码，
   见上面登录那段的提示。

Q：数字和 Claude Code 里 /usage 看到的一样吗？
A：一样，同一个来源。它每分钟自己更新一次，想立刻更新就双击。

Q：它会一直占着 CPU 吗？
A：不会。没在跑会话的时候它降到低帧率，显示器一睡它就完全停下来。

Q：不想让它一直浮在最上层？
A：右键菜单里关掉「始终置于其他窗口之上」。


隐私说明
--------

· 登录令牌存在你自己电脑的
  ~/Library/Application Support/Sundial/ 里，权限仅你可读，
  只发给 Anthropic 官方的地址，不经过任何第三方。
· 它会读取本机 ~/.claude 下的 Claude Code 会话记录，
  但只读会话标题、时间戳、忙/闲标记和 token 计数，不读对话正文。
· 不上传任何东西，没有统计、没有分析。

不想用了：右键 →「退出登录」会删掉令牌，然后把 App 拖进废纸篓即可。
