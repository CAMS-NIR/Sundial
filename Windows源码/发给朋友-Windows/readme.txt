Sundial（Windows 版）
====================

桌面上的一只小太阳，显示你的 Claude 用量还剩多少，
以及正在跑的 Claude Code 会话。


怎么用
------
1. 双击 Sundial.exe。没有安装过程，也不会往系统里写东西。
2. 第一次打开 Windows 可能会弹「已保护你的电脑」的蓝色窗口——
   这是因为这个程序没有花钱买微软的代码签名证书，不是有问题。
   点「更多信息」→「仍要运行」即可。
3. 太阳出现后，双击它（或在它身上点右键 →「登录 Claude 账号…」）。
   会打开浏览器让你登录并授权，然后把页面上给的那串码粘回来。
4. 之后它就一直待在桌面上，自己每分钟更新一次。
   按住太阳可以拖到你喜欢的位置，鼠标移上去会展开详情，移开自动收起。


它显示什么
----------
闲着的时候，桌面上只有一颗太阳，没有卡片——没有事情发生的时候不用占地方。
鼠标移上去就会展开成一张卡片：太阳在中间，左右各一个圈。

· 左边的圈 = 5 小时限额
· 右边的圈 = 用得最紧的那条每周限额（所以标签可能是「每周」，
  也可能是某个模型名——哪条最紧就显示哪条）
· 中间的太阳 = 心情跟着用量走：轻松时咧嘴笑，用了一半抿着嘴，
  快用满了会皱眉、身体发红。
  它还会往用得紧的那一侧探出光芒来回摆动，尖上亮起那一侧的颜色，
  越满越亮——所以就算收起来只剩一颗太阳，扫一眼也知道哪边紧张。
· 下面每有一个正在跑的 Claude Code 会话就是一块，写着标题、
  正在做什么、跑了多久、上下文用了多少。点一下就能把「跑完了还没看」的提示消掉。
· 太阳灰扑扑地睡觉、冒 zzz，意思是现在没有会话在跑，不是坏了。


操作
----
拖动          = 移动位置（放哪儿它记得住）
双击          = 没登录时开始登录；登录了就是立刻刷新一次
鼠标移上去    = 展开明细，移开自动收起
右键          = 菜单
托盘图标      = 左键点一下，把跑丢的桌宠拉回可见的地方

右键菜单：
  登录 / 重新登录 Claude 账号…
  退出登录
  立即刷新
  固定展开用量明细
  打开网页版用量
  把桌宠移回屏幕右下角
  系统模糊背景（实验）
  开机自动启动
  退出 Sundial


说明与已知情况
--------------
· 需要 Windows 10 或 11（64 位）。程序自带运行时，不用另外装 .NET。
· 只支持**原生 Windows 上的 Claude Code**。如果你的 Claude Code 跑在 WSL 里，
  会话记录在 Linux 子系统的文件系统内，这个版本读不到（用量仍然正常显示）。
· 卡片底默认是自己画的半透明圆角底，不是系统模糊。
  原因是 Windows 的亚克力模糊只认整块方形窗口，而这只桌宠收起来是个圆、
  展开是圆角卡片，形状每帧都在变，开了系统模糊反而会在圆角外露出一圈方形的底。
  想试的话右键菜单里有「系统模糊背景（实验）」，Windows 11 上才有效果。
  总之这一块的观感比 macOS 版弱一档。
· 登录令牌用 Windows 自带的 DPAPI 加密，存在 %LOCALAPPDATA%\Sundial\ 下，
  只有你自己的账户能解开。
· 窗口位置和菜单里那两个开关记在 %APPDATA%\Sundial\shell.json，重启后回到原处。
· 它会读取 %USERPROFILE%\.claude 下的 Claude Code 会话记录，
  但只读会话标题、时间戳、忙/闲标记和 token 计数，不读对话正文。
  不上传任何东西，没有统计。

卸载：直接删掉 Sundial.exe，再删 %LOCALAPPDATA%\Sundial 和 %APPDATA%\Sundial
这两个文件夹即可。如果开过「开机自动启动」，先在右键菜单里关掉再删。
